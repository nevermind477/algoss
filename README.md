# algoss

Терминальный визуализатор алгоритмов на Textual. Каждый шаг приходит из генератора,
поэтому анимация, пауза и ручное управление работают без блокировки интерфейса.

## Запуск

    uv run algoss

или без uv:

    pip install -e .
    algoss

Нужен Python 3.10+, терминал с поддержкой цветов и размер окна от 80×24.

## Управление

| клавиша | действие |
| --- | --- |
| `space` | старт / пауза |
| `→` | один шаг |
| `r` | сброс |
| `q` | выход |
| `←` `→` на ползунке | скорость |

Скорость также меняется кликом по полосе в боковой панели.

## Что внутри

- **Сортировки** — пузырьковая и выбором, столбики с подсветкой сравнения и обмена.
- **Основы** — `for`/`if-else` и `while` (гипотеза Коллатца) с подсветкой текущей строки кода.
- **Жадные** — размен суммы монетами, монеты добавляются по одной.
