# algoss

Терминальный визуализатор алгоритмов в стиле классических Linux-утилит (Vim / htop). Шаги вычисляются через чистые генераторы (`yield`), всё управление полностью клавишное (Vim-навигация), интерфейс монохромный со строгими разделителями.

## Запуск

    uv run algoss

или без uv:

    pip install -e .
    algoss

Подходит любой эмулятор терминала (Ghostty, Terminal, iTerm2, Alacritty, kitty), рекомендуемый размер от 80×24.

## Управление в стиле Vim

| Клавиша | Действие |
| --- | --- |
| `space` | Старт / Пауза анимации |
| `n` или `→` | Шаг вперёд (step) |
| `r` | Сброс к первому шагу |
| `j` / `k` (или `↓` / `↑`) | Навигация по списку алгоритмов |
| `h` / `l` (или `←` / `→`) | Предыдущий / следующий режим |
| `1` / `2` / `3` / `4` | Быстрый выбор режима (1: Сорт, 2: Массивы, 3: Поиск, 4: Жадные) |
| `i` или `e` | Фокус на блок настройки чисел для ввода параметров |
| `Enter` | Применить параметры |
| `Esc` | Отмена редактирования (возврат в NORMAL) |
| `g` | Случайная генерация данных (randomize) |
| `-` / `+` | Уменьшить / увеличить скорость анимации (шаг 10%) |
| `q` | Выход из программы |

Мышь также поддерживается: клик по пунктам меню, строкам горячих клавиш или кнопкам `[🎲 Rand]` и `[↵ Применить]` выполняет соответствующие действия.

## Возможности

- **Алгоритмы**:
  - **Сортировки**: пузырьковая (Bubble), выбором (Selection), вставками (Insertion).
  - **Массивы**: два указателя (Two Pointers — поиск пары с заданной суммой), префиксные суммы (Prefix Sums — построение накопительных сумм и сумма на отрезке за O(1)).
  - **Поиск**: бинарный (с указателями L/M/R) и линейный.
  - **Жадные**: пошаговый размен суммы монетами.
- **Интерфейс**:
  - Без громоздких кнопок: компактные списки с курсором `▸`, инверсные плашки и чистый статус-бар.
  - Настройка чисел вынесена в центр — строго между графиком и текущим действием.
  - Памятка по клавишам в один столбик.
  - Адаптивный логотип и пиксель-в-пиксель выровненные углы рамок во всех режимах.
  - Холст со столбиками и динамическими указателями (`L`, `R`, `i`, `j`, `▲`, `•`).
  - Карточка переменных и компактный журнал последних шагов (Trace).
