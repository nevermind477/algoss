# algoss

[![PyPI version](https://img.shields.io/pypi/v/algoss.svg)](https://pypi.org/project/algoss/)
[![Python versions](https://img.shields.io/pypi/pyversions/algoss.svg)](https://pypi.org/project/algoss/)
[![CI](https://github.com/nevermind477/algoss/actions/workflows/ci.yml/badge.svg)](https://github.com/nevermind477/algoss/actions/workflows/ci.yml)
[![License: MIT](https://img.shields.io/badge/License-MIT-white.svg)](https://opensource.org/licenses/MIT)

Терминальный (TUI) визуализатор алгоритмов на Python и Textual в стиле классических Linux-утилит (Vim / htop). Шаги вычисляются через чистые генераторы (`yield`), всё управление полностью клавишное (Vim-навигация), интерфейс монохромный со строгими разделителями.

---

## Установка и запуск

### 1. Мгновенный запуск без установки (рекомендуется)
Если установлен [uv](https://docs.astral.sh/uv/):
```bash
uvx algoss
```

Или через [pipx](https://pypa.github.io/pipx/):
```bash
pipx run algoss
```

### 2. Установка в систему как постоянную утилиту
После установки команда `algoss` будет доступна глобально из любой папки:
```bash
uv tool install algoss
# или:
pipx install algoss
```

### 3. Установка через pip
```bash
pip install algoss
algoss
```

### 4. Запуск из исходников (для разработки)
```bash
git clone https://github.com/nevermind477/algoss.git
cd algoss
uv run algoss
```

> **Требования**: Python 3.10+, поддержка Unicode в терминале. Рекомендуемый размер окна — от 80×24.

## Управление в стиле Vim

| Клавиша | Действие |
| --- | --- |
| `space` | Старт / Пауза автоматического проигрывания |
| `→` / `n` | Шаг вперёд (при воспроизведении) |
| `←` / `p` | Шаг назад / отмотка на 1 шаг (при воспроизведении) |
| `←` / `→` | Переключение разделов (на шаге 1 до запуска) |
| `r` | Сброс к первому шагу |
| `j` / `k` (или `↓` / `↑`) | Навигация по списку алгоритмов |
| `h` / `l` | Предыдущий / следующий раздел |
| `1` / `2` / `3` / `4` | Быстрый выбор раздела (1: Сорт, 2: Массивы, 3: Поиск, 4: Жадные) |
| `i` или `e` | Переход к настройке чисел (режим ввода) |
| `Enter` | Применить введённые параметры |
| `Esc` | Отмена редактирования (возврат в NORMAL) |
| `g` | Случайная генерация данных (randomize) |
| `-` / `+` | Уменьшить / увеличить скорость анимации (шаг 10%) |
| `q` | Выход из программы |

*Мышь также поддерживается: клик по кнопкам режимов, алгоритмам или полям настройки выполняет соответствующие действия.*

## Доступные алгоритмы

- **Сортировки (`[1]`)**:
  - `Пузырьковая` (Bubble Sort)
  - `Выбором` (Selection Sort)
  - `Вставками` (Insertion Sort)
- **Массивы (`[2]`)**:
  - `Два указателя` (Two Pointers — сходящиеся указатели L и R для поиска пары с суммой `target`)
  - `Префиксные суммы` (Prefix Sums — построение накоплений и вычисление суммы на подотрезке `[L..R]` за O(1))
- **Поиск (`[3]`)**:
  - `Бинарный поиск` (с указателями L / M / R и отсечением половин)
  - `Линейный поиск`
- **Жадные (`[4]`)**:
  - `Размен монет` (Coin Change — пошаговый подбор номиналов)

## Интерфейс

- **Динамический ASCII-баннер**: при выборе раздела название отображается крупным символьным шрифтом.
- **Минималистичный переключатель**: чистые кнопки `◄ [1] [2] [3] [4] ►` без обрезков текста.
- **Настройка чисел**: расположена по центру — строго между графиком и карточкой действия.
- **Обратимая пошаговая отмотка**: можно перематывать шаги назад и вперёд в любой момент.
- **Точные рамки**: пиксель-в-пиксель выровненные одинарные углы Unicode.
- **Компактный журнал шагов (Trace)** и классический статусбар в стиле Vim.
