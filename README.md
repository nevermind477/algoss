# algoss

Терминальный визуализатор алгоритмов на Textual. Шаги вычисляются через чистые генераторы (`yield`), поэтому анимация, пауза и пошаговый проход работают без блокировки интерфейса.

## Запуск

    uv run algoss

или без uv:

    pip install -e .
    algoss

Требуется Python 3.10+, поддержка Unicode и размер терминала от 80×24.

## Управление

| Клавиша / Элемент | Действие |
| --- | --- |
| `space` | Старт / Пауза |
| `→` | Один шаг |
| `r` | Сброс к первому шагу |
| `q` | Выход |
| `←` `→` на ползунке | Регулировка скорости (±5%) |
| `🎲 Случайно` | Сгенерировать случайные параметры |
| `↵ Применить` | Применить введённые параметры и перезапустить |

## Возможности

- **Ввод параметров**: можно ввести собственный массив чисел, искомое значение для поиска или сумму и номиналы монет, либо сгенерировать случайный набор кнопкой `🎲`.
- **Алгоритмы**:
  - **Сортировки**: пузырьковая, выбором, вставками, быстрая (Quick Sort), слиянием (Merge Sort), шейкерная (Cocktail Shaker).
  - **Поиск**: бинарный (с указателями L/M/R) и линейный.
  - **Жадные**: пошаговый размен суммы монетами.
- **Интерфейс**:
  - Ч/Б палитра с контрастными жёлтыми акцентами.
  - Отрисовка символами Unicode (`┌─┐│└─┘`, `██`, `▓▓`, `▲`, `▶`, `■`).
  - Компактный холст визуализации и расширенные блоки: состояние переменных, счётчики сравнений/обменов и журнал последних шагов (Trace).
